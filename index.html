PART 01 • WEB DESIGN

HTML কী এবং কেন প্রয়োজন?

HTML-এর পূর্ণরূপ HyperText Markup Language। এটি ওয়েবপেজের কাঠামো তৈরি করার Markup Language; এটি নিজে Programming Language নয়।

মূল ধারণা

HTML কীভাবে কাজ করে?

HTML বিভিন্ন tag ব্যবহার করে ব্রাউজারকে জানায় কোনটি heading, paragraph, image, link বা table।

মনে রাখবে:
HTML = Structure
CSS = Design
JavaScript = Behaviour
HTML Document

HTML ফাইলের মৌলিক গঠন

<!DOCTYPE html> <html lang="bn"> <head> <meta charset="UTF-8"> <title>আমার ওয়েবপেজ</title> </head> <body> <h1>স্বাগতম</h1> <p>এটি একটি অনুচ্ছেদ।</p> </body> </html>

HTML-এর গুরুত্বপূর্ণ অংশ

<!DOCTYPE html> — HTML5 ঘোষণা করে।

<html> — পুরো ডকুমেন্টের root element।

<head> — Metadata ও title রাখে।

<title> — Browser tab-এর শিরোনাম।

<body> — দৃশ্যমান মূল কনটেন্ট।

Tag, Element ও Attribute

Tag: যেমন <p>।

Element: Opening tag, content ও closing tag।

Attribute: Element সম্পর্কে অতিরিক্ত তথ্য দেয়।

<a href="https://example.com"> ওয়েবসাইটে যাও </a>
PART 02 • ESSENTIAL TAGS

প্রয়োজনীয় HTML Tag ও ব্যবহার

গুরুত্বপূর্ণ HTML Tag এবং তাদের ব্যবহার।

Tag কাজ উদাহরণ
<h1> ... <h6> শিরোনাম তৈরি <h1>Title</h1>
<p> অনুচ্ছেদ তৈরি <p>Text</p>
<br> লাইন বিরতি <br>
<hr> বিভাজক রেখা <hr>
<a> Hyperlink তৈরি <a href="...">
<img> ছবি যুক্ত করা <img src="a.jpg">
<ul>, <ol>, <li> তালিকা তৈরি Ordered / Unordered List
<table>, <tr>, <th>, <td> টেবিল তৈরি Row, Heading, Cell
<form>, <input> তথ্য নেওয়া Registration Form

List-এর উদাহরণ

<ol> <li>HTML</li> <li>CSS</li> </ol>

ol = Ordered List এবং li = List Item।

Table-এর উদাহরণ

<table> <tr> <th>নাম</th> <th>রোল</th> </tr> <tr> <td>রাহিম</td> <td>১</td> </tr> </table>

tr = Row, th = Heading, td = Data Cell।

পরীক্ষার টিপস: কোনো tag-এর কাজ লেখার পাশাপাশি একটি code example দিলে উত্তর আরও পরিষ্কার হয়।
PART 03 • DIGITAL ELECTRONICS

Logic Gate: ডিজিটাল যুক্তির ভিত্তি

Logic Gate হলো এমন একটি electronic circuit, যা binary input (0/1) গ্রহণ করে একটি binary output দেয়।

Binary ও Boolean ধারণা

0 = LOW / False

1 = HIGH / True

Boolean algebra-তে চলকের মান 0 অথবা 1 হয়।

Truth Table কী?

Logic Gate-এর সব input combination-এর বিপরীতে output কী হবে, তা যে ছকে দেখানো হয় তাকে Truth Table বলে।

nটি input হলে combination = 2n।
